
# Design Patterns

Este repositorio contiene implementaciones de varios **patrones de diseño** en **Python** y **Java**.

## 📂 Estructura del proyecto

- **`patronDiseñoPython/`**: Implementaciones de patrones en Python.
  - `Builder.py`
  - `Composite.py`
  - `Iterator.py`
  - `Template method.py`

- **`patronDiseñoJava/`**: Proyecto en Java usando patrones de diseño.
  - Código fuente en `src/`
  - Archivos compilados en `out/`
  - Archivos de configuración de IntelliJ IDEA

## 🚀 Patrones incluidos

- Builder
- Composite
- Iterator
- Template Method

## 📖 Notas

- Los ejemplos en Python son independientes.
- El proyecto en Java contiene estructuras organizadas por patrón de diseño.
